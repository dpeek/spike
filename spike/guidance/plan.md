# Plan

Maintain a revisable working notebook, not workflow evidence.

- Decompose the Goal into an ordered sequence of independently safe Changes, each small enough for one fresh implementer to complete and verify in one session.
- Record the sequence, rationale, current focus, and planned Ticket count.
- Normally plan one initial implementation Ticket and one exact review Ticket per Change. Remediation is contingent on review findings, not planned remaining scope.
- Give the initial implementation Ticket the complete Change, required verification, and external postconditions. If several planned implementation Tickets appear necessary, split the Change instead.
- Record decisions, changed assumptions, open findings, and deferred work without copying immutable evidence.
- Pause for operator or design review when the same material finding recurs twice or the direction stops converging.

Revise the Plan when understanding changes; never present planner prose as authoritative completion.
